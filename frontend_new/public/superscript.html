SCRIPT ENGINE

SuperScript

AI 劇本引擎 — 從大綱到分鏡提示詞的完整劇本生產閉環

📖 簡介

SuperScript 是一個基於多智慧體協同（Multi-Agent Pipeline）的 AI 劇本生成引擎，提供：

  • 結構化節點編輯：幕／場／節拍／對白四層架構
  • Git-like 版本控制：分支管理、結構化 Diff、進化評分
  • 多 Agent 協同生成：Architect／Continuity／Writer／Format Agents
  • 節奏與人設一致性：情感曲線分析、角色聲線約束
  • 跨模組整合：SuperTrack 趨勢、SuperForge 視覺提示、SuperGuard 合規

🚀 快速開始

前置需求

  • Docker & Docker Compose
  • Python 3.10+
  • Node.js 18+

後端設置

cd backend

# Start Postgres & Redis
docker-compose up -d postgres redis

pip install -r requirements.txt

psql -h localhost -U superscript -d superscript -f migrations/001_initial_schema.sql

uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# Or: docker-compose up -d

前端設置

cd frontend

npm install

npm run dev

環境變數

建立 .env 檔案：

# Database
DATABASE_URL=postgresql://superscript:superscript_pass@localhost:5432/superscript

# Redis
REDIS_URL=redis://localhost:6379/0

# Celery
CELERY_BROKER_URL=redis://localhost:6379/0
CELERY_RESULT_BACKEND=redis://localhost:6379/1

# AI/LLM
OPENAI_API_KEY=your_openai_key
OPENROUTER_API_KEY=your_openrouter_key
QWEN_MODEL_ENDPOINT=http://localhost:8000/v1

# Security
SECRET_KEY=your-secret-key-change-in-production

🔌 API 端點

端點 方法 說明
/api/v1/scripts GET, POST 列出／建立劇本
/api/v1/scripts/{id} GET, PUT, DELETE 取得／更新／刪除劇本
/api/v1/scenes GET, POST 列出／建立場景
/api/v1/beats GET, POST 列出／建立節拍
/api/v1/characters GET, POST 列出／建立角色
/api/v1/versions GET, POST 列出／建立版本
/api/v1/tasks POST 建立非同步任務
/api/v1/export POST 匯出劇本
/ws/tasks/{id} WebSocket 任務進度即時推送

🤖 AI Agent 分工

Agent 職責 模型選擇
Architect 幕場結構規劃 GPT-4 / Claude-3
Continuity 一致性校驗 Qwen-7B
Writer 對白與動作生成 Claude-3 / GPT-4
Format 格式轉換 Local Formatter

📊 資料模型

核心資料表：

  • scripts — 專案級元資料
  • scenes — 場景節點（含 pgvector 語意索引）
  • beats — 劇本最小推進單元（含 pgvector 語意索引）
  • dialogues — 角色台詞庫
  • characters — 角色設定檔（JSONB voice_profile）
  • versions — Git-like 版本樹

🔗 跨模組整合

SuperTrack → 趨勢熱詞注入大綱生成
SuperForge ← 場景 description 轉視覺 Prompt
SuperTune → 長劇本分段快取、Token 預估
SuperGuard → 合規掃描、版權標註
