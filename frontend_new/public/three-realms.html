🔄

閉環優化機制

驗證失敗自動觸發重新執行，最多 3 次迭代，持續優化方案直到通過。

📖

知識驅動決策

所有決策基於知識庫，非孤立輸入。任務自動關聯相關知識，提供完整決策背景。

💰

輕量級部署

助 LLM 使用小模型，降低 70%+ 計算成本。推薦 DeepSeek API，性價比極高。

🤖

自動任務執行

支持自動執行任務列表，按優先級排序。TODO List 自動修正，結果輸出條件控制。

💾

Markdown 存儲

使用 Markdown 文件格式存儲數據，每個知識點、任務、交互都是獨立文件，易於版本控制。

🔌

向量嵌入支持

集成 Embedding 模塊，支持語義搜索和知識檢索，實現智能知識關聯。

🛠️ 技術棧

Python 3.9+ DeepSeek API OpenAI 兼容 Markdown DB 向量嵌入 YAML 能力描述 CLI 介面
