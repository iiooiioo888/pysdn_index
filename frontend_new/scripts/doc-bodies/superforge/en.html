One-click memory: prompts paired with results

Whenever you generate images with Midjourney, Stable Diffusion, DALL·E, or any external tool, SuperForge intercepts the output via webhook and stores it together with the prompt you used. Not just text—full seed, steps, cfg_scale, model version, negative prompt, everything.

No manual screenshots, copy-paste, or Excel logs. Next time you search, it is there.

💡 Real scenario

You generated a great image yesterday with cinematic drone shot of mountains at golden hour, 8k but forgot to save the file.
No problem—SuperForge already captured it via webhook, including:
・Prompt: cinematic drone shot of mountains at golden hour, 8k
・Negative: blurry, low quality, watermark
・Model: Midjourney v6
・Seed: 48291037 · Steps: 50 · CFG: 7.5
・Output URL: https://cdn.midjourney.com/xxx.png

Semantic search: describe it in plain language

This is not plain keyword matching—it understands meaning. Each time you save a prompt, SuperForge turns the text into a high-dimensional embedding and stores it in a vector database. When you search, your query is embedded too, and results are ranked by cosine similarity.

That means you do not need to remember exact wording—describe the scene you remember and the system finds the matching generation record.

💡 Real scenario

Search: “that neon street photo from last time”
→ The system finds the cyberpunk night scene you saved three weeks ago:
・Prompt: neon-lit Tokyo alley at night, cyberpunk style, rain reflections
・Model: Stable Diffusion XL · Seed: 7283941
・Generated: 2026-03-28 14:32
Even details you forgot are preserved.

It is not “five random files”—a structured version tree so you see what each iteration did.

Webhook sync: stop digging through Discord

Rendered something in Midjourney Discord? SuperForge receives the webhook, updates your library instantly, and you never have to scroll chat history again—everything lands in one place.

Supports Midjourney (Discord bot webhook), Stable Diffusion WebUI (API callback), ComfyUI (node webhook), and any tool that can POST to a URL.

Lightweight storage: text and links only

SuperForge stores prompt text, parameters, and output URLs—not full image binaries. The whole library can be a few MB while tracking tens of thousands of records. Images stay on the original platform (Midjourney CDN, your machine, etc.); SuperForge remembers where to find them.

You avoid storage blowups and backups stay tiny because the core asset is structured text.

🚀 Quick start

From zero to your own prompt library in five steps:

Step 1: Enable the SuperForge module

Open the Pysdn SuperCool console, find SuperForge in the module list, and click Enable. You get an empty knowledge space with default tags and search indexes.

Step 2: Configure webhooks

Go to Integration settings, pick your image tool (Midjourney, Stable Diffusion, ComfyUI, etc.), copy the dedicated webhook URL into that tool. After that, every generation syncs automatically.

Step 3: Import history (optional)

If you kept prompts elsewhere (Excel, Notion, Google Sheets), use batch import. CSV and JSON are supported and will be parsed into indexed records.

Step 4: Search and reuse

Try natural-language queries like “warm sunset landscape” or “last cyberpunk prompt I used.” Combine with tag filters, time range, and model type to narrow results.

Step 5: Favorites and templates

Star prompts for quick access or save parameter bundles as templates to apply in one click next time.

🔗 Works with other modules

SuperTrack → SuperForge: trending assets in

While tracking platforms, SuperTrack can push high-quality visual references into SuperForge—for example when a KOL’s cyberpunk post spikes, the style description becomes a reusable prompt in your library.

SuperScript → SuperForge: script to image

SuperScript can push each scene’s visual description to SuperForge. If the script says “rainy Tokyo street at night, neon on wet pavement,” SuperForge prepares image prompts (e.g. rainy Tokyo street at night, neon reflections on wet pavement, cinematic lighting) ready for Midjourney in one click.

SuperForge → SuperTune: history-informed tuning

SuperTune’s A/B tests can use SuperForge history—for example if prompts with golden hour lighting averaged 35% higher engagement than overcast lighting, it suggests warmer lighting for new content.
