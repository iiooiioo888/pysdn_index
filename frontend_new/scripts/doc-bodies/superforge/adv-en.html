Fuzzy full-text search

Beyond semantic search, SuperForge supports classic fuzzy full-text search. Typing “mountain sunset” finds not only literal matches but also close paraphrases—handy when you remember the gist but not exact wording.

💡 Example

“mountain sunset” can surface “alpine twilight panorama” too. Text hits and semantic similarity are merged and ranked together.

Image-to-image: upload a reference

Found a great reference and wonder if you ever generated something similar? Upload it—SuperForge extracts color, composition, and style features and compares them against stored generation embeddings to find the closest history.

💡 Example

Upload a reference and get the closest past generations with prompts and parameters—for instance a Ghibli-like landscape might match your older Studio Ghibli style, rolling green hills, fluffy clouds run.

Advanced tag management

Besides AI tags, you can define custom tags, hierarchies (e.g. style > cyberpunk > steampunk), and rules that auto-apply tags when conditions match.

  • Custom tags: any dimension you need—e.g. “Client A project,” “Spring 2026 campaign.”
  • Hierarchies: parent/child tag trees; selecting a child can imply the parent.
  • Rules: e.g. “if prompt contains ‘anime’, add #japanese_style”—less manual cleanup.
